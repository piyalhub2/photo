Privacy Policy

My File (part of tonirshaik.github.io/tonirshaik_web) · Last updated: 1 October 2026

"My File" is a personal file manager built and used by its owner, Tonir Shaik, to browse and upload files in his own cloud storage accounts (Google Drive and MEGA). It is not a public service and is not offered to other users.

What the app accesses

When the owner unlocks My File, the app uses the Google Drive API (scope: https://www.googleapis.com/auth/drive) to list, preview, upload, download, rename, move and delete files in the owner's own Google Drive.

What is stored

  • Google credentials (an OAuth refresh token) are stored only as encrypted secrets on the owner's private Cloudflare Worker. They are never placed in the website code or sent to the browser.
  • Your files are not copied to any server operated by this app. File data goes directly between the owner's browser and Google Drive / MEGA.
  • Small thumbnails of images may be cached in the owner's own browser (IndexedDB) for speed.

What is not done

  • No Google user data is sold, shared with third parties, or used for advertising.
  • No Google user data is used to train AI or machine-learning models.
  • No analytics or tracking of Drive content.

Google API Services User Data Policy

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
